# 開工

作者：RaeHo　版本：0.1　授權：CC BY-NC-ND 4.0（詳見 repo 根目錄 LICENSE 與 README）

## 步驟
1. 確認目前的工作資料夾，找到 交接紀錄.md。AGENTS.md 由 Codex 自動讀取，不用重複讀；如果看起來沒讀到，請老師確認是不是開在正確的資料夾。
2. 只讀「## 紀錄」標題底下最上面的一筆，不要讀整份。
3. 用三到五行回報：
   - 上次是哪一天、做到哪裡
   - 產出檔案在哪
   - 還沒完成或卡住的地方
   - 建議的下一步（照上一筆的「下一步」；如果你有補充判斷，要標明是建議）
4. 問老師：「要照這個下一步開始嗎？還是要改方向？」等老師回答後才動手。

## 找不到交接紀錄時
- 找不到檔案，或檔案裡還沒有任何紀錄：告訴老師「這個資料夾還沒有交接紀錄」，詢問是否要先建立（備課資料夾用 lesson-project-init，其他專案用 project-init）。不要自己建立。

## 規則
- 只讀，不修改任何檔案。
- 老師確認之前，不要開始做任何工作。
- 紀錄裡如果出現 token、密碼或學生個資，不要複述，只說「紀錄裡有不該出現的敏感內容，建議刪除」。
