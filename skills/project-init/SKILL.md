# 通用版專案初始化

作者：RaeHo　版本：0.1　授權：CC BY-NC-ND 4.0（詳見 repo 根目錄 LICENSE 與 README）

## 何時使用
- 要在目前的資料夾為一般專案（不限教學）建立規則與交接紀錄。
- 資料夾裡還沒有 AGENTS.md 和 交接紀錄.md。

## 步驟
1. 確認目前的工作資料夾，用一句話告訴使用者「我會在這個資料夾建立檔案」。如果資料夾在會自動同步的位置（Google 雲端硬碟電腦版、OneDrive、iCloud），提醒使用者。
2. 一次問完下面兩題，可以回答「略過」：
   - 這個專案的目的（一兩句話）
   - 固定輸出格式（例如：報告用 Word、資料用表格、網頁用 HTML）
3. 動手之前，先列出打算建立的檔案和內容大綱，等使用者同意後才寫入。
4. 建立 AGENTS.md（模板見下）和 交接紀錄.md（模板見下）。
5. 回報兩個檔案的位置，請使用者讀一次 AGENTS.md，並告訴他任何一行都可以改。

## 一定要遵守
- 不准刪除任何檔案。覺得該刪的，移到「待刪除」資料夾，由使用者自己決定。
- 動手之前先列出計畫，等使用者同意後才執行。
- 金鑰、token、密碼不寫進任何說明檔，也不要在對話中顯示或複製。
- 敏感資料（身分證字號、密碼、金鑰等）不進這個資料夾；遇到時停下來提醒使用者。
- 產出的內容請使用者查證；找不到就說找不到，不要自己編內容。

## 交接
- 每次開工，先讀「交接紀錄.md」最新一筆（最上面那筆），回報上次進度與下一步，等使用者確認再動手。
- 使用者說「收工」時，在「交接紀錄.md」最上面新增一筆。

## 規則
- 已存在的檔案不要覆蓋。先告訴使用者，詢問要略過、合併，還是另存新檔名。
- 不要刪除任何檔案。
- 不要把 token、密碼或任何金鑰寫進 AGENTS.md 或 交接紀錄.md；使用者貼了也不要寫入。
- 不要建立沒有要求的其他檔案（例如 README.md、.gitignore）。
- 不假設使用者是老師，不寫學生程度或學生個資的規則。
