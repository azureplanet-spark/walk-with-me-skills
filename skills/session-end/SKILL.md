# 收工

作者：RaeHo　版本：0.1　授權：CC BY-NC-ND 4.0（詳見 repo 根目錄 LICENSE 與 README）

## 步驟
1. 找目前工作資料夾裡的 交接紀錄.md。找不到的話，詢問老師是否要先建立（備課資料夾用 lesson-project-init，其他專案用 project-init），不要自己建立。
2. 根據這次對話和實際產生的檔案，整理出一筆紀錄，格式如下：
   ----- 格式開始 -----
   ### 2026-12-01 14:30
   - 這次做了什麼：
   - 產出檔案：（用相對路徑）
   - 還沒完成或卡住的地方：
   - 下一步：
   ----- 格式結束 -----
3. 寫入位置：「## 紀錄（最新在最上面）」標題的正下方。如果有「（還沒有紀錄…）」的佔位行，把它拿掉。舊的紀錄一字不動。
4. 日期與時間用電腦系統現在的時間，不要猜。
5. 寫完後，把剛新增的那一筆貼給老師看，問「有要補充或修改嗎？」

## 規則
- 只新增，不修改、不刪除舊紀錄。
- 不記 token、密碼、金鑰，也不記學生姓名、成績或個資；對話中出現時，用「（已略）」帶過。
- 內容要簡短：每個欄位一到三行。
- 不確定的事不要寫成事實，寫「待確認」。
