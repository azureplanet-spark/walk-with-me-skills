# 備課專案初始化

作者：RaeHo　版本：0.1　授權：CC BY-NC-ND 4.0（詳見 repo 根目錄 LICENSE 與 README）

## 何時使用
- 老師要在目前的資料夾建立備課用的專案規則。
- 資料夾裡還沒有 AGENTS.md 和 交接紀錄.md。

## 步驟
1. 確認目前的工作資料夾，用一句話告訴老師「我會在這個資料夾建立檔案」。如果資料夾在會自動同步的位置（Google 雲端硬碟電腦版、OneDrive、iCloud），提醒老師改放在「文件」這類一般位置。
2. 一次問完下面四題，老師可以回答「略過」：
   - 任教科目與年級
   - 學生程度（例如：基礎偏弱、中等、程度分散，或一兩句描述）
   - 固定輸出格式（例如：學習單用 Word、互動網頁用 HTML、題目用表格）
   - 這個資料夾是做什麼的（一兩句話）
3. 動手之前，先列出打算建立的檔案和內容大綱，等老師同意後才寫入。
4. 建立 AGENTS.md（模板見下）。
5. 建立 交接紀錄.md（模板見下）。
6. 回報兩個檔案的位置，請老師讀一次 AGENTS.md，並告訴老師任何一行都可以改。

## 一定要遵守
- 不准刪除任何檔案。覺得該刪的，移到「待刪除」資料夾，由老師自己決定。
- 動手之前先列出計畫，等老師同意後才執行。
- 學生姓名、成績等個資不進這個資料夾；遇到時停下來提醒老師。
- 金鑰、token、密碼不寫進任何說明檔，也不要在對話中顯示或複製。
- 產出的內容（題目、事實、來源）請老師查證；找不到就說找不到，不要自己編內容。

## 交接
- 每次開工，先讀「交接紀錄.md」最新一筆（最上面那筆），回報上次進度與下一步，等老師確認再動手。
- 老師說「收工」時，在「交接紀錄.md」最上面新增一筆。

## 規則
- 已存在的檔案不要覆蓋。先告訴老師，詢問要略過、合併，還是另存新檔名。
- 不要刪除任何檔案。
- 不要把 token、密碼或任何金鑰寫進 AGENTS.md 或 交接紀錄.md；老師貼了也不要寫入。
- 不要在檔案裡寫學生姓名、成績或任何學生個資。
- 不要建立老師沒有要求的其他檔案（例如 README.md、.gitignore）。
